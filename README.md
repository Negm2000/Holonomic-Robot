# Holonomic robot description (early prototype)

First URDF/xacro model and Gazebo setup of the mecanum-wheel base for my B.Sc. graduation project at Cairo University (March 2023): wheel and roller meshes, `ros2_control` tags for Gazebo, and launch files for the robot state publisher and the simulation.

This was the starting point. The software that ran on the real robot is in [ros2-mecanum-bot](https://github.com/Negm2000/ros2-mecanum-bot).
